# Ubikron AI

New here? Give your AI [setup.md](setup.md) first. It connects any AI to Ubikron and checks the setup works, whatever your project.

Ubikron's plugin marketplace for Claude. It holds one plugin, `ubikron`, which teaches an AI agent to run an OSINT investigation in Ubikron: the method, the documentation habits, and how to work from a terminal, the Claude in Chrome side panel, or chat.

```
/plugin marketplace add Ubikron-Tech-Farm/ubikron-ai
/plugin install ubikron@ubikron
```

See [ubikron/README.md](ubikron/README.md) for what it does and what you need.
